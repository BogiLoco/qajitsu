# @qajitsu/adapter-files

QAJitsu local-file adapters of the core installation: tickets, workflow, publisher, bug tracker, resolved bugs and manual cases from files (demo, offline runs, tests).

A [QAJitsu](https://github.com/BogiLoco/qajitsu) plugin (REQ-GEN-11).

## Install

This plugin comes with the CLI: `npm install -g @qajitsu/cli` installs it.

## What it may do

The guard holds the plugin to this manifest at install and before every load (ADR-0015).

- Types: ticket source, ticket workflow, publisher, bug tracker, document source, test-case source
- Permissions: filesystem
- Hosts: none
- Secrets: none
